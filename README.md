# Student Performance Analysis

## Project Overview
This project demonstrates a basic statistical
analysis of student performance using R for
STAT 3030 at the University of Georgia.

## Research Question
Is there a relationship between the number
of hours students study and their exam scores?

## Dataset
A synthetic dataset containing student study
hours and exam scores. No real student
information is used.

## Methods
- Descriptive statistics
- Scatterplots using ggplot2
- Simple linear regression
- Interpretation of model results

## Tools
- R
- RStudio
- ggplot2

## Results
Results will be added after running the analysis.

## How to Reproduce
1. Download the repository.
2. Open the R script in RStudio.
3. Install any required packages.
4. Run the analysis and review the output.
